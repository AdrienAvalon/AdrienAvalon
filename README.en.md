# Hi, I'm Adrien.

**I build tools that make Linux administration and remote connections simpler.**

I'm the systems administrator behind **Avalon Network**. I start with practical needs,
then build, test and document. I also explore self-hosting, AI agents and simulation.

## Avash — remote connections in one place

[![Latest published Avash release](https://img.shields.io/github/v/release/AdrienAvalon/avash?style=flat-square&label=release&color=45c7a7)](https://github.com/AdrienAvalon/avash/releases/latest)

**SSH** terminals, **RDP / VNC** desktops and **SFTP** transfers in a **Rust and Tauri** desktop
application that uses your existing OpenSSH configuration.

## Linux tooling

[**SysAdmin-Tools**](https://github.com/AdrienAvalon/SysAdmin-Tools) — Bash for system diagnostics,
including a documented, **read-only SLES 12 SP5 health check**, validated with ShellCheck.

## Explorations

- [**Destructible FPS**](https://github.com/AdrienAvalon/destructible-fps) — A Rust prototype
  exploring material destruction, physics and server-authoritative multiplayer.
  **Photorealism is a goal**, not the current rendering quality. The playable demo and graphics
  inspector are separate: [status and roadmap](https://github.com/AdrienAvalon/destructible-fps/blob/main/REPRISE.md).
- [**Avalon Research**](https://github.com/AdrienAvalon/avalon-research) — Exploratory work on
  AI agents, persistent memory and symbolic representations.
  Documents in French and English, with links to Zenodo.
