## Linux tooling

Small tools with behavior you can inspect in the source, each scoped to a specific need.

| Project | What it helps with | Before getting started |
|---|---|---|
| [**SysAdmin-Tools**](https://github.com/AdrienAvalon/SysAdmin-Tools) | Diagnose health and performance issues on SLES 12 SP5 servers | Read-only check, documentation and ShellCheck validation |
| [**AVALON-terminal**](https://github.com/AdrienAvalon/AVALON-terminal) | Set up a Zsh/tmux environment for administration | Personal Debian/Ubuntu configuration; the installer changes the system and root account |
| [**Shell-Linux-update**](https://github.com/AdrienAvalon/Shell-Linux-update) | Start an APT update after confirmation | Small historical Debian script to review before running |
| [**secu**](https://github.com/AdrienAvalon/secu) | Understand Unix permission groups | Bash text-processing exercise that writes intermediate files |

## Explorations

### Ava

[**A French-language personal assistant**](https://github.com/AdrienAvalon/ava/tree/ava-main),
with voice and targeted tools for a self-hosted environment. Built on OpenJarvis, the project
remains in development; its capabilities depend on the configured services and explicitly
granted access.

### Destructible FPS

[**A world you can build and destroy**](https://github.com/AdrienAvalon/destructible-fps):
a Rust prototype connecting material-dependent damage, physical bodies and server-authoritative
multiplayer. The local demo is playable; a separate inspector explores fine geometry.

**Photorealism remains a goal.** Linux/Vulkan is the tested platform and servers remain
loopback-only. [See the published status and next steps](https://github.com/AdrienAvalon/destructible-fps/blob/main/REPRISE.md).

### Avalon Research

[**Exploring AI agent memory and architectures**](https://github.com/AdrienAvalon/avalon-research):
independent publications on persistent memory, symbolic representations and specialized modules,
available in French and English with links to Zenodo.

These texts present hypotheses and exploratory experiments; publication does not establish
independent scientific validation.
[Browse the publications](https://github.com/AdrienAvalon/avalon-research#publications).
